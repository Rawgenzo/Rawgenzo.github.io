Rawgenzo は、Apple Silicon のために書かれた RAW 現像ソフトです。macOS の Core Image で RAW を読み、Metal で補正する。余計なものを挟まず、写真と向き合う時間だけを残しました。

目標で頼む

言うのは、
ゴールだけ。

「平均輝度 0.45」「白飛びは 1% まで」。合う露出とハイライト回復は Rawgenzo が探します。AI にスライダーを往復させません。

その場で見える

AI の手つきが、
画面に出る。

開いている写真はすぐに描き直され、AI が動かしたスライダーが光ります。「この写真」と言えば、今見ている写真のことだと伝わります。

取り消し

人の手は、
消さない。

取り消しは頼んだ作業ごと。あなたが後から触った写真は、AI が取り消そうとしても取り消しません。RAW は書き換えません。

鍵を持たない

つなぐのは、
あなたの AI。

Rawgenzo は AI の API キーを持たず、外からの接続も受けません。AI と話すのは手元の MCP クライアント。AI に渡るのは数値と、必要なときの縮小画像だけです。

使いはじめる

  1. Rawgenzo を一度起動する。AI 用の登録(~/.Rawgenzo/.mcp.json)が作られます
  2. Rawgenzo の設定で「AI からの操作を受け付ける」をオンにする(画面にその場で出したいとき)
  3. ~/.Rawgenzo で Claude Code を開き、話しかける。アプリで開いている写真は「この写真」で伝わります

設定のしかた(README)·仕組みの図解

# アプリが作った登録(.mcp.json)を
# Claude Code が読み、Rawgenzo とつながる
cd ~/.Rawgenzo
claude

試作の機能です。書き出しと、アプリで写真を開くことは、まだ AI からはできません。

ルック

なぞるだけで、
空気が変わる。

フィルム風・シネマ風・モノクロ・ノスタルジックの 4 つの組み込みルックに加え、.cube 形式の 3D LUT をフォルダに置くだけで、自分のルックを増やせます。効き具合は「強さ」で 0〜100% まで。すぐに試せる 21 個の LUT も付属しています。

Original 01 Teal & Orange Cinematic

付属の LUT を、Rawgenzo のルックと同じ方法(sRGB ガンマで 3D LUT を適用)で写真に掛けた例です。元の写真は撮影時の JPEG で、Rawgenzo で現像したものではありません。

機能

HDR トーン

白く飛ばさない。
黒く潰さない。

ハイライトの回復とシャドウの持ち上げを、明るさの局所的なマスクで。コントラストは色相を崩さない自前のトーンカーブで ±120 まで。

非破壊編集

RAW には、
指一本触れない。

調整は RAW の隣の小さな JSON に自動で保存。いつでも最初からやり直せます。

DSC03356.ARW.rawgenzo.json
{
  "cameraProfileID" : "sony.ilce-7sm3",
  "settings" : {
    "exposure" : 0.5,
    "contrast" : 0.3,
    "look" : {
      "id" : "builtin.film",
      "strength" : 0.7
    }
  }
}

クロップと傾き補正

傾けても、
枠ははみ出さない。

±15° の傾き補正。枠は常に回転後の画像の内側に収まり、四隅に何も無い部分が写り込みません。

0.0°

レンズ補正

レンズの癖は、
カメラが覚えている。

ARW に記録された補正値から、周辺減光・歪曲・倍率色収差を補正。初めは撮影時のカメラの設定に従い、写真ごとに切り替えられます。

  • 周辺減光
  • 歪曲
  • 倍率色収差

色別補正

桜の花びらだけを、
桜色に。

8 色の帯ごとに色相・彩度・輝度を整えるほか、スポイトで拾った色だけを狙えます。白に近い淡い花びらにも色を足せて、空や枝はそのまま。AI に頼めば、効く範囲と強さは Rawgenzo が決めます。

  • 8 色
  • 拾った色
  • 効く場所を表示

トーンカーブ

平板な光に、
メリハリを。

輝度・R・G・B のカーブを、クリックした所に点を置いて作ります。明るさだけを変えて色合いを保つか、彩度も一緒に上げるかは「彩度の連動」で。グラフの後ろには、カーブを掛ける前のヒストグラム。AI からも、点や決まった形でカーブを指定できます。

  • 輝度・R・G・B
  • 16 点まで
  • 彩度の連動
  • プリセット

編集前と見比べる

押している間だけ、
撮ったままに。

「/」キーを押している間、プレビューが編集前に戻ります。切り抜きも傾きも外した、撮ったままの姿。離せば編集後に戻ります。「すべて初期値に戻す」と違って編集は消えないので、どれだけ変えたかを何度でも確かめられます。

  • 「/」を押している間
  • 切り抜き・傾きも外す
  • 編集は消えない

構図の答え合わせを、

コマンドライン

フォルダごと、
ターミナルから。

アプリと同じ現像エンジンを使う rawdev を同梱。フォルダを渡せば中の RAW をまとめて現像します。出力先や形式はアプリの書き出し設定と共有。

rawdev
$ rawdev check
Core Imageの対応カメラ数: 932
対応: Sony Alpha ILCE-7S III

$ rawdev name "{date}_{model}_{seq:3}" ~/Pictures/ARW
DSC03356.ARW → 20260621_ILCE-7SM3_001
DSC03402.ARW → 20260621_ILCE-7SM3_002
DSC03451.ARW → 20260622_ILCE-7SM3_003

$ rawdev develop ~/Pictures/ARW --hdr 0.6 --look builtin.film
$
